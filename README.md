# My Scheduled Tasks

A ReactJS midterm project for creating, displaying, editing, updating, and deleting scheduled tasks.

## Run the project

1. Open a terminal inside the `scheduled-tasks` folder.
2. Run `npm install`.
3. Run `npm start`.

## Requirements included

- Task name must contain at least 5 characters.
- Priority must be from 1 to 10.
- Every task must have at least 1 sub task.
- Description must contain at least 3 characters.
- Duration must be at least 60 minutes.
- Priorities 1–3 display as Not Important, 4–7 as Standard, and 8–10 as Important.
- Duration is converted from minutes to hours.
- Tasks over 24 hours display as Long Task. Tasks of 24 hours or less display as Short Task.
- Every task includes Edit and Delete buttons.
- Tasks are divided into Not Important, Standard, and Important categories.
- Numbering starts at 1 separately inside each category.
